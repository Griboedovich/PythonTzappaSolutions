# О репозитории

В данном репозитории хранятся решения моего варианта в цаппе. В виду процедурной генерации задач, этот репозиторий имеет смысл только в качестве демонстранции возможных способов решения задач.

# Структура

- Practical_task (номер практической)
	- Task (номер задания)
		- Method (номер способа) - один из способов решения задачи
		- Test (номер теста) - вспомогательный файл для отладки конкретного способа)
	- LeetCode (решения задач с leetcode, в которых мне пришлось прибегнуть к локальному редактору кода)
- Python for fun - тут лежать решения задач, которые мне интересно делать
	- Shaders - задачи по шейдерам (тут лежать также задачи необходимые для выполнени ПР1)
